Ejercicio 4: Suma de dos números con prompt()

Escribe un programa que pida al usuario ingresar dos números y muestre la suma. Usa prompt() para pedir los datos, Number() para convertirlos y console.log() para mostrar el resultado.

Se abrirán dos cuadros de diálogo.
